Setup no longer has manual steps, so more of your teams can use Orbit every day.
The GitLab Orbit CLI connects to the graph on your GitLab instance by default.
You do not need GitLab Duo Agent Platform to use Orbit from your own agents.

## What shipped

- `glab orbit setup` sets up Orbit for your agent with one command.
- Any agent or IDE can connect through the Model Context Protocol (MCP).
