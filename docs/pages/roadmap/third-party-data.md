Many teams keep planning, documentation, and team discussion in tools other than GitLab.
Orbit will connect this data to the graph, next to your code and GitLab data.
For each source, Orbit will either index the data or query the source when an agent asks.
Orbit will check the permissions of the source before it returns a result.

## First sources

- Jira
- Confluence
- Slack
- ServiceNow
