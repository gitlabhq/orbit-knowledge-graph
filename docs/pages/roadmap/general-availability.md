GitLab will support Orbit for production use on GitLab.com.
On GitLab Self-Managed, production support starts with GitLab 19.5.

## Included at general availability

- A graph of your planning, merge request, pipeline, and security data
- A graph of the code on the default branch of each project
- GQL queries from agents and the API
- Permission checks on every result
