Your teams know which repositories make up a service, and who owns it.
We will explore a file that you add to your repositories to declare these entities and the relationships between them.
For example, the file can label a repository as a backend service that depends on another service.
Orbit will add the entities to the graph, so agents can answer questions about services, not only about projects.
