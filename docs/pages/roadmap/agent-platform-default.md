Orbit in GitLab Duo is on by default from GitLab 19.5.
An administrator can turn it off for the instance.

## Next

- Agents in GitLab Duo Agent Platform use the graph when it can answer a question, with no mention of Orbit in the prompt.
- More GitLab features use the graph for context.
