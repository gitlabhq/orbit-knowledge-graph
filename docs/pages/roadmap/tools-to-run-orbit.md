We will remove the manual steps from Orbit setup, so more of your teams use Orbit every day.
The Orbit CLI connects to the graph on your GitLab instance by default.
You do not need GitLab Duo Agent Platform to use Orbit from your own agents.

## Planned changes

- You will turn on Orbit for an instance or a top-level group with one setting.
- You will see progress while the first index builds.
- You will set up Orbit for your agent with one command.
- You will connect any agent or IDE through the Model Context Protocol (MCP).
