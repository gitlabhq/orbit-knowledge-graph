GitLab Orbit is the context graph of your software lifecycle.
It connects your code, merge requests, pipelines, work items, and vulnerabilities in one graph that your AI agents can query.
Ask what breaks if a service changes, or which CI/CD jobs fail most.

## Common questions

### Who can see which data?

Each answer shows only the data that your GitLab role lets you see.
Orbit stores no permission data, and the graph is read-only.

### What does GitLab Orbit need?

The graph of your group needs GitLab Premium or Ultimate with GitLab Orbit [purchased](https://about.gitlab.com/gitlab-orbit/).

### Which agents work with GitLab Orbit?

`glab orbit setup` sets up Claude Code, Codex, GitLab Duo, OpenCode, or Pi.

### Where are the docs for using GitLab Orbit?

This site is the product overview and the developer docs.
To use Orbit, see the [GitLab Orbit documentation](https://docs.gitlab.com/orbit/).
