A few questions come up in almost every conversation about Orbit.
When does Orbit index my branches?
Can Orbit connect data from my other tools?
When is Orbit available on GitLab Dedicated?

The Orbit roadmap answers these questions in one public place that you can share.

## What is on the roadmap

Each item has a status and a target quarter.
Many items link to the documentation.
We plan about two quarters ahead.
Items with the status "exploring" are ideas. Their design can still change.

The roadmap comes from two sources:

- What customers tell us in calls, issues, and support requests
- What the Orbit team learns when we build and run Orbit

## Roadmap updates

The roadmap is a set of Markdown files in the Orbit project on GitLab.
When a plan changes, the change is a commit.
For the history of every item, see the [roadmap commit history](https://gitlab.com/gitlab-org/orbit/knowledge-graph/-/commits/main/docs/pages/roadmap).

## Quarters

The roadmap uses GitLab fiscal quarters.
For example, FY27 Q4 is November 2026 to January 2027.
