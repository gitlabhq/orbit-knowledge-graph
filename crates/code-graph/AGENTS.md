# Code-graph

Language-specific code belongs in `crates/code-graph/src/v2/langs/{generic,custom}/`. Keep it out of the shared linker, pipeline, or analyzer. Those are performance-sensitive. Per-language branches there add complexity for every language. Express special handling as a **generic hook the pipeline already exposes**, such as a per-language import or scope hook via config. You can also reuse an existing edge type. Do not add a language branch in shared code. When adding a new language, include a `code-indexing-benchmark.yaml` entry. Also add test fixture repos under `fixtures/code/` so the team can evaluate coverage.
